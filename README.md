# Smart To-Do Dashboard

A modern productivity and task management web application built using HTML, CSS, JavaScript, and Chart.js.

This project helps users manage daily tasks, track productivity, analyze weekly/monthly performance, and monitor progress using interactive charts and analytics.

---

## Features

- Add, edit, delete tasks
- Mark tasks as completed
- Automatic category detection
- Task search functionality
- Completion analytics dashboard
- Weekly productivity tracking
- Performance percentage chart
- Monthly growth analysis
- Streak tracking system
- Task history tracking
- LocalStorage data persistence
- Multi-page dashboard design
- Responsive and modern UI

---

## Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- Chart.js
- LocalStorage API

## Smart Features

### Automatic Category Detection
Tasks are automatically categorized into:
- Study
- Coding
- Gym
- Personal

based on keywords entered by the user.

---

## Charts & Analytics

The dashboard includes:

- Task Completion Chart
- Weekly Progress Chart
- Performance Percentage Graph
- Monthly Skill Growth Chart

using Chart.js.

---

## Data Storage

All tasks and analytics are stored using the browser's LocalStorage, so data remains saved even after refreshing the page.
